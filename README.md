# Sagehen Hydromet

Hydromet dashboard for Sagehen Creek near Truckee, California: the basin above USGS 10343500 (27.7 km2). Same layout and QC as Alta Hydromet; everything loads in the browser, no GitHub Action.

Live: https://tyler-y42.github.io/Sagehen.Hydromet/

- Precipitation: the field station Geonor weighing gauge (UC NRS Dendra, raw frequency converted with the logger calibration), SNOTEL 541/539/540/428/834 and RAWS via Synoptic, Hobart Mills (NV Energy).
- Flow and water temperature: USGS 10343500. Snow: SNOTEL via AWDB. Radar: IEM IEMRE (Stage IV, MRMS) and the IEM NEXRAD mosaic. Forecast: NWS Reno grid REV 28,105. Cameras: PhenoCam sagehen, sagehen2, sagehen3.
- Source research and QC tests: RESEARCH.md. Self test: index.html?selftest
